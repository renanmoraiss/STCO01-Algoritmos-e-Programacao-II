COMPLEXIDADE DE TEMPO:

                Melhor Caso | Caso Médio | Pior Caso
Bubble Sort        O(n²)        O(n²)        O(n²)
Insertion Sort     O(n)         O(n²)        O(n²)
Selection Sort     O(n²)        O(n²)        O(n²)
Merge Sort       O(n*logn)    O(n*logn)    O(n*logn)  
Quick Sort       O(n*logn)    O(n*logn)      O(n²)   

*OBS: no Bubble Sort, quando o vetor está totalmente ordenado e
utilizando uma flag de otimização, sua complexidade é O(n).

COMPLEXIDADE DE ESPAÇO:

Bubble Sort      O(1) (In place)
Insertion Sort   O(1) (In place)
Selection Sort   O(1) (In place)
Merge Sort       O(n) (Aloca memória para vetores auxiliares, utilizados para cópias e intercalção).
Quick Sort       Melhor/Médio Caso: O(log n) e Pior Caso: O(n)
